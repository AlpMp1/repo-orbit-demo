Core capability

从“问代码”升级到“维护仓库”

RepoOrbit 的目标是让 AI 处理真实工程任务，而不只是生成单个函数。每次运行都会产出结构化仓库报告、任务计划、补丁记录、测试结论和审查意见。

01

Repository Intelligence

自动读取目录、依赖、路由、状态管理、接口层和测试日志，生成模块地图、风险文件、边界关系和技术债列表。

02

Agent Task Planner

把“升级依赖”“拆分组件”“补测试”“修复 bug”等目标拆成可执行任务，附影响范围、验收标准和回滚方案。

03

Patch & Test Loop

生成代码补丁并根据 lint、typecheck、unit test、e2e test 的输出进行多轮修复，直到形成可审查的 PR 结果。

Roadmap

从演示原型到可复用开发工作流

后续版本会把仓库接入、运行日志、评测数据和 PR 报告进一步产品化，让团队可以持续复用同一套 AI 维护流程。

Phase 1

静态仓库分析

支持上传仓库结构和关键文件，生成 repo map、风险清单和技术债 backlog。

Phase 2

工具链接入

接入本地 AI 编程工具，保留每轮命令、输出、失败原因和修复记录。

Phase 3

自动评测集

构建多仓库 benchmark，统计任务成功率、测试通过率和人工节省时间。

Phase 4

团队协作

支持任务模板、审查规则、PR 报告导出和历史运行对比。
