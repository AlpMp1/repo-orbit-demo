# RepoOrbit Demo

RepoOrbit is a static product prototype for an AI repository maintenance cockpit. It demonstrates repository understanding, multi-agent planning, patch/test loops, PR review output, benchmark planning and roadmap.

## Files

- `index.html`: single-file static demo website
- `application_04_v2.txt`: application description text for the MiMo form

## Suggested deployment

Upload `index.html` to GitHub Pages, Vercel, Netlify, or any static frontend hosting platform.
